Laudicom Finance Agent

Laudicom Finance Agent is an internal financial administration assistant intended for use by authorized staff of participating companies. It connects to Visma.net ERP to retrieve accounting information and supports review of supplier records and purchase invoices.

The current Visma service integration requests read-only API access. Any future write functionality would require separate permissions and an updated description of the service.

The assistant may also process invoice information received through a shared Microsoft 365 finance mailbox and use an AI service provided by Anthropic (Claude) to assist with analysis. Access to each Visma administration requires authorization by its administrator.
